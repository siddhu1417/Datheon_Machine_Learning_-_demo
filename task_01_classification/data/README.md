# Dataset

`iris.csv` is the project-provided Iris dataset. It contains 150 flower samples, four numeric measurements (`sepal_length`, `sepal_width`, `petal_length`, `petal_width`), and the categorical `species` label. The included CSV is the default data source; no download or API key is needed.

The program can instead use scikit-learn's built-in Iris or Wine data by changing `DATASET` in `config.py` to `sklearn_iris` or `wine`.
